G-PANEL V6 UI

Base: IPTV Panel V5.1

UI changes:
- New G-PANEL logo integrated in admin.php, editor.php and importer.php
- New modern dark SaaS dashboard styling
- Responsive sidebar and navigation
- Updated login screen branding
- Shared assets in /assets

To replace the logo later:
- Replace /assets/g-panel-logo.png with your new horizontal PNG
- Optionally replace /assets/g-panel-mark.png with the compact icon/mark
- Keep the filenames unchanged so no PHP changes are required.

Backend logic was preserved from V5.1.
PHP syntax was validated for all PHP files.
